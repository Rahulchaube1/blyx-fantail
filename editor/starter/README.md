# Fantail starter

Resolve a layered setting and report where an invalid override came from.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Fantail** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0
15
1
5
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/fantail) · [View the release](https://github.com/Rahulchaube1/blyx-fantail/releases/tag/v0.1.0)
